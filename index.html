Android · Kotlin

Campus Event Manager

A native Android app in Kotlin that runs campus events across three roles — student, organization, and admin. Firestore real-time listeners drive live headcounts and capacity limits, and students check in by scanning a QR code that only works when GPS confirms they are physically on campus. A Cloud Function fans out FCM push notifications whenever an organization posts an event, pruning dead device tokens as it goes.

Kotlin Firebase Firestore Cloud Functions
Android · Kotlin · AI

DocQuizAI

An Android app that answers questions from a reference document using Claude. A loaded PDF is stripped to plain text by PDFBox-Android and becomes the knowledge base; a floating, draggable overlay built on MediaProjection, VirtualDisplay and ImageReader then captures the screen, reads the question with ML Kit OCR, and returns the answer in place — without the user leaving the page.

Kotlin ML Kit OCR Claude API MediaProjection
